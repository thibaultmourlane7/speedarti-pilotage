Remplacer uniquement :

- `src/app.js`
- `src/app.bundle.js`
- `src/styles.css`
- `src/tags.js`
- `docs/TAGS.md`

Ne pas modifier :

- `index.html`
- `src/data.js`
- `src/state.js`

## Nouveautés V6

- validation humaine obligatoire avant passage officiel d'un projet en `Terminé` ;
- demandes de validation avec accepter / refuser ;
- alertes automatiques pour échéances dépassées et blocages ;
- notification lue distincte de notification résolue ;
- résolution automatique des alertes quand la cause disparaît ;
- regroupement anti-spam des erreurs techniques identiques ;
- centre de notifications avec onglet Alertes ;
- synthèse colorée Retards / Blocages / Validations / À planifier sur Aujourd'hui ;
- simulateur IA multi-scénarios : nouvelle tâche, progression, blocage, clôture projet, erreur technique ;
- progression routinière appliquée automatiquement ;
- proposition IA de clôture soumise à validation humaine.

Toutes les fonctions ajoutées sont balisées dans `docs/TAGS.md` et les balises restent invisibles dans l'interface.
